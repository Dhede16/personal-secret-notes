# SECRET NOTES — PROJECT SPECIFICATION

## 1. Project Overview

Buat sebuah aplikasi web bernama **Secret Notes**, yaitu aplikasi catatan pribadi dengan mekanisme **client-side encryption menggunakan AES-256-GCM**.

Aplikasi memungkinkan user:

* Melihat daftar catatan tanpa memasukkan encryption key.
* Melihat judul catatan tanpa dekripsi.
* Membuat catatan baru.
* Mengenkripsi isi catatan menggunakan AES-256-GCM.
* Membaca isi catatan dengan memasukkan encryption key.
* Melakukan dekripsi di browser.
* Mengedit catatan.
* Menghapus catatan.
* Mengunci kembali catatan setelah selesai dibaca.
* Melihat animasi visual proses encryption dan decryption.

Fokus utama project adalah **security, privacy, simplicity, dan visualisasi proses cryptography**.

# 3. Important Security Architecture

Aplikasi harus menggunakan **client-side encryption**.

Artinya:

> Encryption dan decryption isi catatan dilakukan sepenuhnya di browser.

Backend **tidak boleh mengetahui encryption key maupun plaintext isi catatan**.

Arsitektur:

```text
User
 │
 ▼
Vue.js
 │
 ├── Plaintext
 │
 ▼
AES-256-GCM
 │
 ├── Ciphertext
 └── IV
 │
 ▼
FastAPI
 │
 ▼
notes.json
```

Untuk decryption:

```text
notes.json
 │
 ▼
FastAPI
 │
 ▼
Vue.js
 │
 ├── Ciphertext
 ├── IV
 └── User Key
 │
 ▼
AES-256-GCM
 │
 ▼
Plaintext
```

# 4. Encryption Requirements

Gunakan **AES-256-GCM**.

Encryption key harus berukuran:

```text
256 bit = 32 bytes
```

Gunakan Web Crypto API:

```javascript
crypto.subtle.encrypt()
crypto.subtle.decrypt()
crypto.getRandomValues()
```

Jangan membuat implementasi AES sendiri.

Jangan menggunakan:

```javascript
Math.random()
```

untuk kebutuhan cryptographic randomness.

Gunakan random IV/nonce untuk setiap proses encryption.

Plaintext:

```javascript
TextEncoder
```

Decrypted bytes:

```javascript
TextDecoder
```

Ciphertext dan IV harus dikonversi ke format yang aman untuk JSON, misalnya Base64.

# 25. Important Cryptography Principle

Jangan membuat animasi yang membuat seolah-olah AES benar-benar bekerja seperti:

```text
S → Sa → Say → Saya
```

AES-256-GCM bekerja terhadap data bytes secara keseluruhan.

Animasi tersebut hanya digunakan sebagai **visual representation**.

Implementasi sebenarnya harus tetap:

```text
Plaintext
   ↓
TextEncoder
   ↓
AES-256-GCM
   ↓
Ciphertext + IV
   ↓
Base64
   ↓
FastAPI
   ↓
JSON
```

Decryption:

```text
JSON
   ↓
FastAPI
   ↓
Base64 Decode
   ↓
Ciphertext + IV
   ↓
AES-256-GCM + Key
   ↓
TextDecoder
   ↓
Plaintext
```
